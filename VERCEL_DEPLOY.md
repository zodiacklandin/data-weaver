## 🚀 Deploy in 3 Steps

### Step 1: Create GitHub Repository (2 min)

1. Go to [github.com/new](https://github.com/new)
2. Repository name: `vektor-ecommerce` (or your choice)
3. Description: "VEKTOR - Premium E-Commerce Platform"
4. Choose Public (recommended) or Private
5. Click "Create repository"
6. Copy the URL shown (e.g., `https://github.com/YOU/vektor-ecommerce.git`)

### Step 2: Push Code to GitHub (1 min)

In your project directory:

```bash
git init
git add .
git commit -m "Initial commit: VEKTOR e-commerce platform"
git branch -M main
git remote add origin https://github.com/YOU/vektor-ecommerce.git
git push -u origin main
```

### Step 3: Deploy to Vercel (Auto)

1. Go to [vercel.com/new](https://vercel.com/new)
2. Click "Import Git Repository"
3. Paste your GitHub URL
4. Click "Import"
5. Select "Next.js" (auto-detected)
6. Click "Deploy"

**Done!** 🎉 Your site is live in ~60 seconds

## 🆘 Need Help?

### Common Issues

**"Build failed"**
- Check build logs in Vercel dashboard
- Usually means missing environment variables
- Solution: Add `.env.local` variables in Vercel dashboard

**"Blank page"**
- Open browser console (F12)
- Check for error messages
- Hard refresh (Ctrl+Shift+R)

**"Page takes forever to load"**
- Clear browser cache
- Vercel cache might need invalidation
- Check network tab in DevTools (F12)
